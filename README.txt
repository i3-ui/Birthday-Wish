MUHAMMAD Moazzam — BIRTHDAY SURPRISE WEBSITE

Included:
- index.html
- birthday-song.m4a (the song file supplied by you)
- photos/memory1.jpg, memory2.png, memory3.jpg

IMPORTANT:
Keep index.html, birthday-song.m4a, and the photos folder together in the same website folder.

How it works:
1. Visitor opens the website and first sees the black-and-gold song screen.
2. Visitor presses “Please play the song”. The supplied song starts and loops in the background.
3. The countdown and the birthday surprise begin only after the song starts.
4. The music continues while moving through the screens. Browsers require the visitor's tap to start audio, so the first Play button is necessary.

GitHub Pages hosting:
1. Create a public GitHub repository.
2. Upload index.html, birthday-song.m4a, and the complete photos folder.
3. Open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the generated GitHub Pages link and share it with Ali.
